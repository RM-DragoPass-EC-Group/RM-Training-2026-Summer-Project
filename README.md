# RM-Training-2026-Summer-Project

> Introduction and Requirements for the Training Project

本项目是 RM2026 暑期招新培训的最终项目。各小组需要综合运用培训中学习到的机械、硬件、电控与调试知识，合作完成一辆麦克纳姆轮小车的完整制作。

## 项目总览

本项目内容涵盖机械结构搭建、电控程序开发、电气走线整理、调试测试与最终展示。通过这个项目，同学们需要将硬件、电路、通信、控制和调试方法综合应用到一个完整的机器人系统中，体验从方案设计到成品实现的完整工程流程。

项目按照完成度划分为不同阶段，建议各组分阶段推进。不同职位之间可以并行开发，也需要在关键节点完成联调。

每小组由三位电控、两位硬件和两位机械组成，分组名单可参考：

## 项目要求

### 阶段一：底盘基础运动

本阶段目标是完成小车底盘的基础搭建与电机控制，使小车能够稳定、可靠地完成定速直线行驶。

#### 整车

- 小车底盘外观完整，接线正确。
- 小车可以定速跑直线。

#### 机械

- 完成小车底盘的机械结构设计，并进行 3D 打印。
- 小车机械结构完整、可靠。

#### 硬件

- 完成小车电气连接规划。
- 连通所有硬件设备。

#### 电控

- 完成底盘 F401 的电机驱动编写。
- 实现 C 板和 F401 的通信。
- 使用 PID 实现小车定速行驶，可以暂不使用遥控。

---

### 阶段二：遥控底盘与云台搭建

本阶段目标是完成云台结构与供电走线，并通过遥控实现麦克纳姆轮底盘的全向平移和旋转。

#### 整车

- 小车底盘、云台外观完整。
- 云台走线完整。
- 小车可以通过遥控控制，实现麦轮的全向平移和旋转。

#### 机械

- 完成云台设计。
- 连接底盘和云台。

#### 硬件

- 使用课上设计的分线板。
- 完成云台供电和走线。

#### 电控

- 实现 C 板对底盘 F401 的控制。
- 通过 USB 无线串口模块实现遥控通信链路。
- 完成底盘的运动学解算，并使用遥控控制底盘运动。

---

### 阶段三：整车联动控制

本阶段目标是完善整车结构、走线与控制逻辑，实现底盘和云台的完整遥控联动。

#### 整车

- 小车整体外观完整，走线优美。
- 实现完整遥控，包括底盘和云台。
- 可以同时控制底盘和云台的运动。

#### 机械

- 尝试设计并解决云台旋转导致的缠线问题。

#### 硬件

- 整理并完善走线和连接。
- 可以尝试自行设计降压板，代替底盘电机驱动模块的 5V 和 3V3 供电。

#### 电控

- 实现 C 板的 CAN 通信。
- 完成对云台电机的控制。

---

### 阶段四：视觉联调

本阶段目标是与视觉部分进行联调，完成云台自瞄功能。

- 与视觉联调，完成云台自瞄。

---

### 其他要求

- 底盘F401只负责底盘电机驱动模块的驱动，整车的控制及遥控等功能都由c板负责
- 电控使用 GitHub 进行项目管理。
- 尽量使用 RTOS 架构开发。
